# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful and constructive, assume good faith, focus criticism on the work and not
the person, and keep discussions about the software and its use. Harassment, personal attacks and
discriminatory language are not acceptable in issues, pull requests or any other project space.

Concerns can be raised privately through the contact given on the maintainer's GitHub profile
(<https://github.com/SpencerFrangou>). Reports are handled confidentially; the maintainer may edit, remove
or lock contributions that breach these standards.
